# TaskFlow App

Um aplicativo móvel desenvolvido em **React Native (Expo)** focado no gerenciamento simples e eficiente de tarefas pessoais. O aplicativo permite que o usuário crie, edite, visualize, filtre e exclua tarefas, tudo com navegação em abas e uma interface com temas Claro e Escuro.

## 🚀 Tecnologias Utilizadas

- React Native (Expo SDK 54)
- TypeScript (Tipagem forte e sem o uso de `any`)
- React Navigation (Bottom Tabs e Native Stack)
- AsyncStorage (Armazenamento e persistência local)
- Context API (Gerenciamento global para Tema, Autenticação e Tarefas)
- Fetch API (Consumo de API Externa)

## ⚙️ Como executar o projeto

1. Certifique-se de ter o Node.js e o Expo CLI instalados.
2. Clone o repositório.
3. No terminal, execute:
   ```bash
   npm install
   ```
4. Em seguida, inicie o servidor:
   ```bash
   npm start
   ```
5. Leia o QR Code no seu celular com o aplicativo do **Expo Go** (Android/iOS).
